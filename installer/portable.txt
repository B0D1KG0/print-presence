EN: This file keeps Print Presence portable: settings and the picture cache are saved
    in the "data" folder next to PrintPresence.exe, nothing is written to the system.
    Delete this file to use the normal %APPDATA%\PrintPresence folder instead.

    Удали файл, чтобы программа хранила настройки в %APPDATA%\PrintPresence.
